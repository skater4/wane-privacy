# wane-privacy

Публичная страница политики конфиденциальности приложения Wane
(`com.wane.sleep`) — обе локали на одной странице.

Живёт на GitHub Pages: https://skater4.github.io/wane-privacy/

Этот адрес указывается в Play Console в двух местах: карточка приложения
и раздел Data safety. Менять его после публикации неудобно.

Исходники приложения лежат в приватном репозитории отдельно; здесь только
документ, который по своей природе публичен.
