# wane-privacy

Публичная страница политики конфиденциальности приложения Wane — **обеих
версий и обеих локалей на одной странице**: Android (`com.wane.sleep`) и
iPhone (`com.stanmanman.Wane`).

Живёт на GitHub Pages: https://skater4.github.io/wane-privacy/

Этот адрес указывается в трёх местах, и менять его после публикации
неудобно:

- Play Console — карточка приложения и раздел Data safety;
- App Store Connect — поле Privacy Policy URL.

## Как устроена страница

Один `index.html` без зависимостей. Переключатель `English` / `Русский`
показывает одну из двух секций; без JavaScript видны обе, и страница
остаётся читаемой.

Приложения устроены по-разному, поэтому внутри каждого языка то, что
различается, разведено метками платформы: что хранится на устройстве,
чего приложение сознательно не делает, разрешения и оплата. Общее —
отсутствие сбора данных, дети, изменения, контакт — общее и есть.

**Различия, о которых легко забыть при правке.** У Android — оверлей,
права администратора и счётчик касаний; он не трогает системную
громкость. У iPhone касаний нет вовсе, вместо них движение телефона;
единственное разрешение — уведомления; зато он **убавляет системную
громкость** и играет фоновый шум, и об обоих сказано прямо.

Исходники приложений лежат в отдельных репозиториях; здесь только
документ, который по своей природе публичен.
